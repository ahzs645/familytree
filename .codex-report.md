# Report presentation/export depth work package

## Implemented

- Added a saved per-report output language override (`App language`, English, Vietnamese, Arabic) and threaded the resolved locale/direction through AST localization, preview, HTML, print, PDF, and CSV output without changing the app locale.
- Added preview zoom with fit-width and stepped percentage controls.
- Added report watermark text/opacity and table presentation settings for grid lines, repeated print headers, and striped rows. These settings are normalized and persisted only in saved report recipes, without changing shared book/chart presentation schemas.
- Added an accessible CSV export sheet for comma/semicolon/tab delimiters, LF/CRLF line endings, and optional headers; extended the CSV renderer/export pipeline accordingly.
- Added saved-report dirty tracking and save/discard/cancel guards for report-type changes, saved-report loads, internal-link navigation, and browser unload.
- Expanded Today Report using the MacFamilyTree `CoreTodayReport.strings` behavior: selected date, person/family event-type toggles, grouped event-type output, name/date sorting, and anniversary age.
- Expanded Changes List using `CoreChangesListReport.strings`: person/family/source/place/media/other filters, author and still-in-database columns, type/author grouping, and earliest/latest ordering.
- Added and registered a privacy-aware DNA Report for `DNATestResult` records with person, normalized ATDNA/MTDNA/YDNA kind, provider, haplogroup, marker/SNP presence, and raw-file references. It uses all standard report export paths.
- Added Statistics drill-down sheets with editor links on the Statistics route and supported every Statistics chart section with direct underlying-record mapping (persons, families, or places).
- Added English and natural Arabic catalog entries for all new UI and generated structural labels.

## Scope notes

- PDF export continues to use the app's established browser print dialog path; watermark and table print CSS are included there.
- Statistics drill-down for derived marriage metrics maps the records represented by locally available family dates/events; malformed or date-less source records cannot be associated with a bucket and are intentionally omitted.
- No package, Vite, CI, storage schema, or dependency changes were made.
