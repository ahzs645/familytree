# Extended event fields + shared-place edit safeguard

## Implemented

- Added canonical optional event fields `time`, `address`, `agency`, and `cause` to the event record API and to person/family event editing.
- Displayed the fields in the Events/Family Events lists, Person Editor, Family Editor, interactive-tree inspector, configurable Events List report, person/narrative reports, and exported website event tables.
- Added English and Arabic UI translations for the new controls and shared-place decision.
- Added GEDCOM import/export mappings for `TIME` beneath `DATE`, plus event-level `ADDR`, `AGNC`, and `CAUS`, including multiline addresses and family events.
- Expanded `.mftpkg` event extraction for the Mac Core Data columns `ZTIME`, `ZAGENCY`, and `ZCAUSE` on person and family events.
- Replaced the event place selector with an inline, existing-place-aware name editor. Renaming a place used by other events now opens an accessible decision sheet with the other-reference count and Rename / Create New / Cancel choices.
- Implemented change-logged shared-place rename and event-only clone paths. The clone retains descriptive place metadata, drops database identity and the old direct coordinate pointer, receives the new name, and repoints only the current event.

## Scoped down / intentionally skipped

- The MacFamilyTree 11 Event Core Data entity exposes `time`, `agency`, and `cause`, but no event-address persistence column (`ZADDRESS` belongs to the source-repository entity in the inspected schema). Consequently `.mftpkg` import cannot populate event `address`; the web editor and GEDCOM round-trip fully support it.
- A cloned place does not reuse the original direct `Coordinate` reference because that coordinate's inverse `place` reference still belongs to the original place. Other descriptive/template fields are retained; this avoids creating a misleading cross-place coordinate link.
- No dataset migration/version bump was needed because records use extensible field envelopes and all four additions are optional.
